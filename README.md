## 📖 About The Project

Recipe Book is a modern Android application that helps users discover, share, and organize their favorite recipes. Built with Material Design principles and modern Android technologies.

### ✨ Features

- 🔐 **Authentication** - Secure login/register with Firebase
- 📸 **Image Upload** - Cloudinary integration for images
- 🏠 **Home Screen** - Category tabs with swipe navigation
- 🔍 **Search** - Real-time recipe search by title/category
- 📝 **CRUD Operations** - Create, Read, Update, Delete recipes
- 👤 **User Profile** - Personal profile with user's recipes
- 🎥 **Video Links** - Attach YouTube tutorials
- ⚡ **Smooth UI** - Shimmer loading and Material Design 3

## 🛠️ Built With

- **Java** - Primary language
- **Firebase Auth** - Authentication
- **Firestore** - Cloud database
- **Cloudinary** - Image hosting
- **Picasso** - Image loading
- **ViewPager2** - Swipeable tabs
